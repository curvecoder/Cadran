Im **Kategorieformular** legen Sie neue Ausgabenkategorien an oder ändern bestehende, passen Symbole und Farbcodes an, konfigurieren mehrsprachige Übersetzungen und bestimmen Kategorien für Gehaltseinnahmen.

## 2. Referenztabelle der Aktionen

| Markierung | Bedienelement | Aktionstyp | Handlungsanweisung |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Eingabe des Kategorienamens** | **HIER EINGEBEN** | Geben Sie den Anzeigenamen der Kategorie ein (z. B. *Lebensmittel*, *Fahrzeugwartung*). |
| <kbd>2</kbd> | **Mehrsprachige Übersetzungen** | **WÄHLEN / EINGEBEN** | Hinterlegen Sie lokalisierte Übersetzungen für die einzelnen Sprachen (Englisch, Französisch, Spanisch, Deutsch). |
| <kbd>3</kbd> | **Farbauswahl & Hex-Code** | **FARBE WÄHLEN** | Wählen Sie eine markante Farbe für Diagramme, Grafiken und Buchungs-Badges. |
| <kbd>4</kbd> | **Auswahl der übergeordneten Kategorie** | **OPTION WÄHLEN** | Wählen Sie eine Hauptgruppe, um eine Unterkategorie anzulegen, oder lassen Sie das Feld leer, um eine oberste Gruppe zu erstellen. |
| <kbd>5</kbd> | **Symbolauswahl & Vorschau** | **HIER KLICKEN** | Öffnen Sie die Symbolauswahl, um ein passendes Symbol aus der integrierten Bibliothek zu wählen. |
| <kbd>6</kbd> | **Schaltfläche „Kategorie speichern"** | **HIER KLICKEN** | Speichern Sie die Kategorie und kehren Sie zum Kategorie-Explorer zurück. |

---

## 3. Oberste Kategorie vs. Unterkategorie

- Für eine **oberste Hauptkategorie** lassen Sie das Feld **Übergeordnete Kategorie** (<kbd>4</kbd>) leer.
- Für eine **Unterkategorie** wählen Sie in der Auswahl (<kbd>4</kbd>) eine bestehende Hauptkategorie. Die Unterkategorie übernimmt automatisch die Einordnung als Einnahme oder Ausgabe ihrer Hauptkategorie.

---

## 4. Schritt-für-Schritt-Anleitung

1. **Kategorienamen eingeben**: Tragen Sie die Bezeichnung in Feld (<kbd>1</kbd>) ein.
2. **Übergeordnete Gruppe zuweisen**: Wählen Sie in der Auswahl (<kbd>4</kbd>) eine Hauptgruppe oder lassen Sie sie für eine neue Gruppe leer.
3. **Symbol & Farbe wählen**: Klicken Sie auf **Symbol wählen** (<kbd>5</kbd>) und wählen Sie eine Badge-Farbe (<kbd>3</kbd>).
4. **Übersetzungen konfigurieren**: Wählen Sie weitere Sprachen (<kbd>2</kbd>), wenn Sie mehrsprachige Berichte verwenden.
5. **Speichern**: Klicken Sie auf **Kategorie speichern** (<kbd>6</kbd>).
