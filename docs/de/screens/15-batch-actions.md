Die **Leiste für Stapelaktionen** wird aktiv, sobald im Journal mehrere Buchungen ausgewählt sind. Damit stimmen Sie mehrere Buchungen in einem Schritt ab, kategorisieren sie neu oder passen sie an.

## 2. Referenztabelle der Aktionen

| Markierung | Bedienelement | Aktionstyp | Handlungsanweisung |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Kontrollkästchen „Alle auswählen"** | **KLICKEN / UMSCHALTEN** | Wählen Sie mit einem Klick alle sichtbaren Buchungen der aktuellen Tabellenseite aus oder ab. |
| <kbd>2</kbd> | **Kontrollkästchen der Zeile** | **KLICKEN / UMSCHALTEN** | Wählen Sie einzelne Buchungen für die Stapelaktion aus. |
| <kbd>3</kbd> | **Zähler der ausgewählten Elemente** | **STATUS-BADGE** | Zeigt in Echtzeit die Anzahl der ausgewählten Buchungen, die auf eine Aktion warten. |
| <kbd>4</kbd> | **Aktion zur Sammelabstimmung** | **HIER KLICKEN** | Wenden Sie einen Abstimmungsstatus (z. B. *Abgestimmt* oder *Verbucht*) auf alle ausgewählten Buchungen an. |
| <kbd>5</kbd> | **Schaltfläche „Auswahl aufheben"** | **HIER KLICKEN** | Hebt die Auswahl aller Zeilen auf und schließt die schwebende Leiste der Stapelaktionen. |

---

## 3. Empfohlenes Vorgehen für die monatliche Kontoauszugsabstimmung

1. **Nach Auszugszeitraum filtern**: Wählen Sie den Vormonat über die Zeitraumauswahl im Kopf des Journals.
2. **Mit dem Bankauszug vergleichen**: Haken Sie die Kontrollkästchen (<kbd>2</kbd>) der Buchungen ab, die auf Ihrem Bankauszug bestätigt sind.
3. **Sammelabstimmung**: Klicken Sie auf die Aktion **Abstimmen** (<kbd>4</kbd>), um alle geprüften Buchungen zu sperren.
4. **Auswahl aufheben**: Schließen Sie die Leiste (<kbd>5</kbd>), um zur normalen Journalansicht zurückzukehren.
